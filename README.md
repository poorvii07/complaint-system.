# Apartment Complaint Management System

A simple web-based system for residents to submit and manage apartment complaints.

## Features

- Submit complaints
- Enter resident name and room/flat number
- Select complaint category
- Describe the complaint
- Search complaints by category
- Delete complaints
- Mark complaints as resolved

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## How to Run

1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
npm install
